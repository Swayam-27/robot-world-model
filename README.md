# Robot Arm World Model

**Can a neural network learn a robot simulator from camera frames alone, well enough to rank robot policies the way the real simulator does?**

A diffusion world model learns to simulate a 7-joint robot arm (MuJoCo Pusher-v5). Ten RL policies are then run inside the learned "dream" and ranked, and the ranking is compared with the real one.
